## 6. OpenRouter 影片 API 呼叫方式

來源：https://openrouter.ai/docs/guides/overview/multimodal/video-generation （2026-10-12）

影片走**非同步工作**流程：送出請求後拿到工作 ID，再輪詢狀態或等 webhook 通知。這和 `/chat/completions` 不同。

| 動作         | 方法與路徑                                                                                                                                                                                 |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 送出工作     | `POST /api/v1/videos` → 回 202，內容為 `{ id, polling_url, status: "pending" }`                                                                                                            |
| 輪詢狀態     | `GET /api/v1/videos/{jobId}` → status：`pending` → `in_progress` → `completed` 或 `failed`；完成時回傳 `generation_id`、`unsigned_urls`、`usage.cost`、`usage.is_byok`，失敗時回傳 `error` |
| 下載影片     | `GET /api/v1/videos/{jobId}/content?index=0`。`unsigned_urls` 沒有預先簽名，下載時要帶 `Authorization` 標頭                                                                                |
| 列出影片模型 | `GET /api/v1/videos/models`（內含 `pricing_skus`，例如依解析度的每秒價格），或 `GET /api/v1/models?output_modalities=video`                                                                |

**請求欄位**：`model`（必填）、`prompt`（必填；部分模型給了 frame_images 就可省略）、`duration`、`resolution`（480p／720p／768p／1080p／1K／2K／4K）、`aspect_ratio`、`size`（WxH，可代替 resolution＋aspect_ratio）、`frame_images[]`（`frame_type`：first_frame／last_frame）、`input_references[]`（參考圖）、`generate_audio`（有音訊的模型預設 true）、`seed`、`callback_url`、`provider`（傳給特定供應商的參數）。同時給 `frame_images` 與 `input_references` 時，以 `frame_images` 為準。

**Webhook**：用 `callback_url` 設定，或在 workspace 設預設網址。事件有 `video.generation.completed`、`failed`、`cancelled`、`expired`。每次通知帶 `X-OpenRouter-Idempotency-Key`（格式 `<job_id>-<status>`）。設定簽章密鑰後，會帶 `X-OpenRouter-Signature`（`t=...,v1=...`），以 HMAC-SHA256 對時間戳加原始 body 驗證。

**限制**：影片生成不支援 ZDR（零資料保留）。開啟 ZDR 強制時，影片請求不會被轉送。
