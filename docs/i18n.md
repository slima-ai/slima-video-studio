# 介面語言（i18n）

App 的介面有繁體中文（`zh-TW`，預設）與英文（`en`）。**英文介面還在分批轉換中**（計畫與進度：HQ `staff/handoffs/2026-10-23-studio2-vs-english-ui-plan.md`），全部轉完之前語言選項不開放給一般使用者（`ENGLISH_UI_READY = false`）：設定的「跟著系統」一律是繁體中文；開發時用環境變數 `SVS_LOCALE=en` 或在設定檔寫 `"language": "en"` 才會看到英文。

## 怎麼運作

- 核心在 `packages/schema/src/i18n/`（不加任何套件）：`t('key', { 參數 })`、`msg('key')`、`formatDate`、`formatNumber`、`getLocale`／`setLocale`。主行程、畫面與 `packages/*` 共用同一份。
- 字串檔在 `packages/schema/src/i18n/locales/zh-TW/*.ts`（**key 的型別從這裡來**）與 `locales/en/*.ts`。每個功能一個檔案（`menu.ts`、`help.ts`…），改不同頁的 PR 不會碰到同一個檔案。`en` 的型別要求和 `zh-TW` 有**同一組 key**：少一條或多一條都編譯不過。
- key 是語意名稱（`help.step1.title`），不是中文原文。參數寫成 `{name}`，型別會檢查名稱有沒有傳；兩種語言的參數集合必須一樣（測試會擋）。
- 語言怎麼決定（主行程，`locale-service.ts`）：環境變數 `SVS_LOCALE`（非打包版才生效）＞ 設定的 `language`（`system`／`zh-TW`／`en`）＞ 作業系統語言（中文給 `zh-TW`，其他給 `en`）。主行程算好後用 `app.locale` 與 `locale.changed` 事件告訴畫面；畫面（`renderer/lib/i18n.tsx`）收到就換語言並整棵重畫。
- **測試固定用繁體中文**：e2e 的 `launchApp` 設 `SVS_LOCALE=zh-TW`，vitest 預設語言就是 `zh-TW`。原因：預設是「跟著系統」，CI 的 Linux 系統語言多半是英文，不固定的話整套測試會一起變英文。要測英文就在測試裡 `setLocale('en')`，或 e2e 用 `test.use({ appEnv: { SVS_LOCALE: 'en' } })`。
- **假語系** `en-XA`（`SVS_LOCALE=en-XA`）：英文拉長約 40%、字母換成帶記號的、前後加括號——畫面上還是正常中文的地方就是漏網的寫死字串，被截斷或爆版的地方就是英文會爆版的地方。

## 怎麼加一條字串

1. 在對應功能的字串檔加 key：`zh-TW/<功能>.ts` 與 `en/<功能>.ts` 各一條（兩邊 key 相同）。
2. 程式裡 `t('功能.key')`；有參數就 `t('功能.key', { count })`。
3. **不要在模組載入時就固定的地方呼叫 `t()`**（常數表、陣列、模組層級的 `const`）：它會把語言鎖在載入的那一刻，切換語言不會變。改成存 `msg('功能.key')`，用的時候再 `t(label)`。`msg()` 回傳的不是字串（所以直接放進畫面或當字串用會編譯不過），一定要經過 `t()`。
4. 單複數：英文要 `key_one`／`key_other` 兩條（`t('key', { count })` 自動挑），中文只要 `key_other`。
5. 日期、數字用 `formatDate`／`formatNumber`，不要寫死 `'zh-TW'`。
6. 一句話要完整：不要把「中文 + 變數 + 中文」拆成兩三條拼起來，英文語序不同；整句放一條、用 `{參數}`。

## 守門

- **棘輪**（`tools/i18n/ratchet.test.ts`）：`tools/i18n/baseline.json` 記每個檔案現在有幾條寫死的中文字串；任何檔案**增加**、或新檔案出現中文字串，測試就失敗；**減少**也會失敗，要跑 `pnpm i18n:baseline` 把基準降下來（這樣轉好的地方不會被加回去）。全部轉完後基準是空的，換成 ESLint 規則（`no-restricted-syntax` 擋含中文字的字串，例外只有字串檔、測試與模型提示範本）。
- **型別**：`t('不存在的 key')` 編譯不過；英文少 key 編譯不過。
- **字串檔測試**（`packages/schema/src/i18n/i18n.test.ts`）：英文沒有中文字、沒有空字串、兩邊參數一致；英文介面不用 `node` 這種術語（對應中文的 `plain-words.test.ts`）。

## 搬一整個檔案的工具

`tools/i18n/codemod.mjs` 把檔案裡寫死的中文換成 `t()`／`msg()`，並寫進字串檔（可以在最新的 main 上重跑）：

```
node tools/i18n/codemod.mjs extract <功能> <檔案…> --out extract.json     # 列出要換的字串與不能自動換的地方
# 把英文寫進 translations.json：{ "中文原文": "English" } 或 { "中文原文": { "en": "English", "key": "語意key" } }
node tools/i18n/codemod.mjs apply <功能> <檔案…> --translations translations.json
```

自動換 JSX 文字、JSX 屬性、函式裡的字串與樣板字串；模組層級的字串換成 `msg()`（用的地方要手動改成 `t(…)`，型別會擋沒改的）；用 `+` 拼接、拿來比對資料的中文不動、會列出來手改。換完要 `prettier --write`，並跑 `pnpm i18n:baseline`。
